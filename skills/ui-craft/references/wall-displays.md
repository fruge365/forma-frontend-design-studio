# 大屏视觉方向与验证

先明确观看者站在哪里、会看几秒、看到信息后要做什么。询问或沿用已知的屏幕比例、分辨率与拼缝位置。只知道分辨率时，先用常见宽屏试排，把实地观看距离留给现场核验。

| 观看任务 | 主画面与视觉语言 | 怎么判断这套设计成立 |
| --- | --- | --- |
| 指挥中心追踪移动目标，判断何时可接入 | 用大幅轨迹、拓扑或地平线表达位置关系。暗底保留层次，一条高亮轨迹对应选中的目标，窗口、箭头和时间使用相同标识。辅助遥测贴近它解释的对象。 | 切目标或时间时，主图、数值、时间窗口同时改变。远处应能读到目标名称、当前状态与下一关键时刻。 |
| 大厅、港口、车站指引人流 | 用高明度底色、粗字、大数字和方向箭头组成一条视线。把正在办理的班次放大，其后的班次按实际办理顺序续排。把“改到 05 闸”写出来。 | 遮住颜色仍能找到闸口和改动。读者用几秒就能回答“哪一班、去哪里、从几号口走”。 |
| 能源或生产监控墙观察异常 | 用单线图、厂区流程或负荷曲线组织屏面；设备编号、单位、告警与更新时间贴近相应节点。基础网格退后，重要状态在全屏占稳定位置。 | 一段数据缺报后，能区分缺报和零值。同一异常可以从总览追到节点和对应时间。 |

**画幅。** 16∶9 把中部留给需要跨区阅读的主要关系，边缘承载解释。21∶9 增加有效横向视野或同时可读的行列；文字和圆形保留原比例。大屏挂高、隔着玻璃或位于拼接墙时，观众要读的目标、时刻、闸口应避开上沿或拼缝。把边缘位置留给现场能舍弃的信息。

**图形与动效。** 星下轨迹、距离环和预测线各自代表可解释的数据。按一个时间源更新相互关联的图与数字。模拟回放写日期、时区或时间口径。需要动效时用于标出新事件，并给出静态状态；检查减少动态偏好的显示。持续闪烁会让下一条告警难以发现。

**验证。** 用 1920×1080、1366×768 和代表性超宽比例检查整屏是否完整。关闭指针提示后，读出一次关键变化。再用 390px 宽的独立页面读同一条状态，必要时把主图变成简报或按行排的旅程信息。桌面截图能验证像素布局；实体字高、反光、观看距离与拼缝要在目标设备上确认。
