# 数据大屏与分析看板

## 区分三种观看模式

| 模式 | 用户行为 | 设计重点 |
| --- | --- | --- |
| 远距离常驻大屏 | 站立或远处扫描，少操作 | 大字、稳定区域、异常突出、少滚动 |
| 桌面分析看板 | 筛选、比较、追溯 | 交互查询、细节解释、时间与单位 |
| 调度工作台 | 监控后立即处理 | 异常列表、位置上下文、明确动作 |

先确认目标比例、物理显示环境和使用距离。若信息缺失，可选择 16:9 桌面大屏作为初始设计并说明假设，同时提供较窄窗口可用布局。不能通过 `transform: scale()` 把 1920px 画布缩成难读的手机页面；固定画布模式应与普通响应布局区分。

## 信息结构

先回答“现在怎样、哪里异常、为什么、下一步是什么”。关键指标置于稳定位置，主图表达主要业务关系，辅助图与列表补充解释。地图只有在地理位置影响判断时才使用；拓扑、流程、产线或时间线可能更准确。

不要为了大屏气氛添加无来源旋转地球、扫描线、随机跳数和装饰仪表盘。空间图需要清楚说明是地理地图还是示意图。全国/城市边界与实际地理数据不一致时不能当作精确地图。

## 字号与色彩

- 常见远距离 1080p 大屏可从标题 28–36px、主数字 36–56px、标签 16–20px 试起，再按实际观看距离验证。数字大不代表所有标题都要大；让异常与核心指标最容易识别。
- 深色背景可降低常驻显示眩光，但不是大屏唯一选择。用相近但可辨的背景层次组织区域，边框与网格低对比，数据和状态保持高对比。
- 强调色集中在核心数据、当前选择与异常。健康/警告/严重使用颜色加文字或图形；不要全部发光。小面积发光可作氛围，不覆盖细线与数字。
- 避免过细字体、全大写微小标签和过长横排说明。将单位与数值区分但保持可读。

## 图表选择与诚实表达

| 问题 | 优先图形 | 必备说明 |
| --- | --- | --- |
| 随时间变化 | 折线/面积 | 时间范围、采样粒度、单位 |
| 类别间比较 | 条形/柱形 | 类别、数值、可理解的排序 |
| 占比 | 堆叠条形或少类别环形 | 总量、占比合计、图例 |
| 分布与离群 | 直方/散点/箱线 | 维度、范围、数据含义 |
| 阈值与目标 | 子弹图、进度与数值 | 目标、当前值、阈值 |
| 空间与连接 | 地图/拓扑 | 位置含义、连线含义、图例 |

柱形通常从零起；非零起点需要理由与明显标注。折线可裁剪范围以显示变化，但轴刻度必须清楚，不能夸大趋势。避免双轴造成误导、3D 饼图扭曲面积和无解释的平滑插值。

每个指标说明单位、时间范围和必要口径。比较基准一致；百分比与百分点区别清楚。图例名称与颜色对应，悬停提示不应是获取全部信息的唯一途径。关键数据提供文字摘要或表格替代。

## 用趋势做调度决策

定时采样的实测序列在缺报处断开，保留前后时间间隔。真实的 0 落在零刻度，孤立的有效点仍用点标出。来源另外提供了插补值时，才按估算值标明。这样值班员能分清“本站已无车”和“本站还未上报”。[ONS 折线图指南](https://service-manual.ons.gov.uk/data-visualisation/chart-types/line-chart)

实测和预测共用时间轴时，在交界处直接写“实测至 07:00”或标出预测时段，配合线型或区域底色。摘要和明细带上相同的时点与性质。如果终点是预测，差值也要写成“预计净变化”，否则读者可能把预计的降幅当成已经发生。只拿到点预测时保留点值。若来源提供的区间会改变判断，再画出范围并解释上下界的含义。[ONS 图表中的不确定性](https://service-manual.ons.gov.uk/data-visualisation/guidance/showing-uncertainty-in-charts)

区域合计取决于各站上报时，先核对覆盖数。三个站中两个上报，共 7 辆，可以写“已上报 2/3 站，合计 7 辆”，或将完整区域总量标为缺报。覆盖范围变化时，比较相同站点的变化或暂缓给出升降幅度。

让用户从趋势走到具体对象。按当前区域、时点和调度依据列出候选站，显示影响次序的事实。如果清单固定按交班时刻生成，把这个时刻写在清单标题旁。按缺车程度排名时，保留实测为 0 的车站，缺报站单独提示核查。加入调度清单后更新计划状态，库存按其数据来源更新。

## 实时、刷新与异常

显示更新时间与时区，定义过期状态。数据加载失败后保留旧数据时明确“数据已过期”，不静默显示“运行正常”。离线、零值、缺失值不可互相替代。

真实数据刷新不破坏当前筛选与用户焦点；异常信息稳定可读，不被轮播瞬间带走。自动轮播可暂停；动画不能掩盖变化。后台页签降低不必要刷新频率。

模拟使用稳定且一致的数据集并标明“模拟数据”；模拟刷新可改变已定义的状态或更新时间，但不能伪装实时连接。图表、总计、异常列表与导出应相互一致。

## 验证

检查目标比例与 1366×768 等较小桌面窗口，必要时在全屏模式测试。离开全屏仍能操作；全屏失败有提示。远距离可读性需要实际人眼或现场反馈，不用一张缩略截图宣称已验证所有显示场景。
