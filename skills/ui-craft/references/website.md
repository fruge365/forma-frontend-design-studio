# 官网、产品与内容展示

## 内容顺序

根据用户决策顺序组织，而非固定“英雄区 + 三张卡片 + 评价 + CTA”。首屏应能回答：这是什么、适合谁、为何值得继续、下一步是什么。产品复杂时先展示使用情境；视觉产品先展示实物；机构官网优先可信信息与入口。

一个常用但非强制的路径：**价值主张 → 产品/体验证据 → 差异化能力 → 适用场景 → 具体下一步**。若没有评价、客户、数字等真实证据，就不编造社会认同。原型可用明确的示例内容，不营造真实背书。

## 版式与主视觉

- 首屏建立一个强视觉关系：产品与文字、人物与环境、标题与版面、或可交互样稿。不要让抽象渐变球成为不相关业务的默认主视觉。
- 标题要有内容，不用“重塑未来、无限可能”替代清晰产品说明。标题可短，正文补足适用对象与价值。主 CTA 使用动作结果，如“查看产品”“预约体验”，避免多个同权重按钮。
- 高品质感来自克制、对齐、字阶与素材品质。大标题、大留白、浅灰底本身不是品质证明。保证首屏在常见笔记本高度仍能看见主行动或下一段线索。
- 长页面通过图文比例、背景层次和内容形态变化制造节奏；不是每个区块都交替背景色，也不是每段都套一张圆角卡片。
- 产品系列展示保持比较维度一致；单品页用局部细节、使用场景和规格帮助决策。规格要标明单位与条件，不把参数堆在首屏。

## 导航与行动路径

导航数量由内容决定，桌面避免过多顶级项。滚动导航可保持可见，但不要占据过多高度。移动导航按钮应有展开状态并能键盘操作；打开菜单后保证可关闭和焦点合理。

锚点对应真实内容，预留固定导航偏移。购买、预约、下载与联系入口具有实际目标；若是本地原型，则打开清楚标记的预览流程。视频播放按钮应真的播放可用素材，或者不用播放按钮。

## 页面质量细节

- 主视觉在手机上重新裁切或重排，不能简单压扁。产品关键部位、人物脸部和文字不被裁掉；避免把关键文案烘焙在图片里。
- 首屏资源不依赖用户滚动后才加载，屏外图片可延迟。没有素材时可做精心设计的原生矢量或 CSS 展示，但不冒充真实产品摄影。
- 联系表单明确必填字段、提交状态与后续预期。没有服务端则说明本地模拟，不显示“已发送给销售”之类虚假成功。
- 尊重浏览器滚动与用户阅读，不强制吸附每屏、截获滚轮或播放有声内容。动效增强内容，而非阻碍访问。
- 页尾提供合理的信息收束与导航。法律、备案、政策和地址使用真实信息；缺失时不编造。

## 不同领域的迁移

科技官网可借鉴产品展示的聚焦与克制；文化内容可用编辑式版面与图文叙事；企业服务可用工作流与界面样稿建立信任；电商需要价格、规格、库存与交易路径优先。品牌研究提供方法，不决定所有网站必须像某一个品牌。
