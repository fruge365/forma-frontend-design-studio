# 外观偏好、阅读位置与动态反馈

## 分开保存选择和实际外观

产品提供“跟随系统、浅色、深色”三种选项时，保存用户选的模式。在跟随系统时，用此刻的系统偏好推导实际外观，并响应页面打开期间的系统变化。用户明确选浅色或深色时，按该选择显示。切回跟随系统，应立即采用此刻的值。验收一次完整切换，尤其是当前系统颜色恰好与手选颜色相同时。Web 可用媒体查询或 `matchMedia` 的 `change` 事件检测变化，设置合适的 `color-scheme` 也能让原生控件跟上主题。[MDN 系统配色偏好](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-color-scheme) · [MDN 媒体查询变化](https://developer.mozilla.org/en-US/docs/Web/API/MediaQueryList/change_event)

主题、文字大小等阅读偏好与文章位置、工单状态分别管理。切换外观要保留正在阅读的段落、输入中的内容和正在查看的记录。存储不可用时，当前页面仍应能切换；持久化范围按实际能力说明。

## 为两种主题分别试色

先给正文、辅助说明、浮层、边界、操作和状态选语义色，再逐层查看它们的实际背景。对半透明前景或遮罩，应取叠加后的颜色计算对比。深底 `#17252D` 上，38% 白的对比约为 3.5∶1，同一位置改用 62% 白约为 6.8∶1。若用作正常字号的必要说明，前者达不到 4.5∶1。换到选中行、图片或弹层时重新取色。用实色色块取样可避开文字抗锯齿边缘，随后用真实字体和字号看片段。[W3C 文本对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

在两种主题中分别检查判断所必需的折线、游标、选中标志和输入边界，与各自相邻的颜色比较。WCAG 非文本对比针对识别组件、状态或理解图形所需的视觉信息，通常至少 3∶1；纯装饰网格可保持低调。分不清系列时增加标签、线型或标记。键盘焦点轮廓应能与业务选中样式同时辨认。[W3C 非文本对比](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

若颜色本身就是内容，例如印迹与纸色、材料样本或作品原图，保留能说明对象的颜色。主题应调整环绕它的背景、图注和操作入口；若使用更暗的展示衬底，再次核对图与背景之间的边界。

## 让长文重排后仍接得上

用目标字体和真实段落试排行长。夹入一行中英混排的专名、全角标点、长标题和图注，检查回行后是否容易找到下一行。宽屏调整正文栏宽，窄屏优先调整边距。字号与行距共同影响每屏可读的行数，用原稿试出适合该读物的档位。用户放大文字或覆盖行、段间距后，还要检查章名、图注和设置按钮能完整显示。手机上重点检查最大字号下底栏是否遮住末段，设置面板关闭后焦点是否回到原按钮，触碰按钮边缘能否操作。[W3C 文本间距](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)

在改字号或行距前记下阅读线附近的内容 ID。按稳定的章节、段落 ID 找回正文，需要时保存该段相对阅读线的偏移。超长段落可以进一步锚定段内句子或短片段。字体加载、设置面板关闭和工具栏高度变化都可能影响最终位置，布局稳定后再校准。恢复位置时给明确打开的章节链接优先权；正文修订导致段落消失时，可回到原章节。验证用户读了一半时放大、刷新、从目录跳到另一章，分别核对段名与焦点。

关闭设置时，浏览器将焦点还给触发按钮也可能使画面滚动。验收时同时读取关闭后的焦点和正文阅读线。先恢复焦点，再按需要校准原段位置；触发按钮不可见时要确认返回的位置对键盘用户也说得通。

## 动态界面里的选择和执行

从提示、工单或播放队列里查看一项时，可同时存在键盘焦点、正在查看的条目、待执行对象与当前执行对象。按业务定义分别命名，以标题或状态词、图形和布局区分。单纯点行预览不应改写执行历史。真正执行后，在原操作附近显示执行对象和结果，更新相关记录；若支持撤销，说明撤销改变的是本机计划、业务记录还是实际设备状态。

在减少动效的环境下，进场移动、视差、持续脉冲等装饰可静止。进度、完成、错误、当前执行的位置依然要通过文字或静态形状表达。自动刷新时保留键盘焦点；需要朗读时宣布有意义的操作结果，逐帧刷新数值无需反复播报。验收时在两种主题和降低动效的组合下执行同一条操作，核对结果、当前对象和日志。[MDN 减少动态效果偏好](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)
