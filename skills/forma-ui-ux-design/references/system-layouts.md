# 业务系统的布局与配色

同一家制造企业里，采购员可能在核对两张单据，计划员在找产线空档，主管在审批变更。让用户完成动作所需的**对象关系**占据最多版面。第一次试排先放入一笔真实长度的记录及其上下文，再定栏宽和信息密度。

## 根据操作选择主区域

| 操作与场景 | 桌面布局和视觉重心 | 可用宽度变小时保留什么 |
| --- | --- | --- |
| 财务对账、采购核价，逐字段比两份记录 | 原始单与候选单并排，共用字段顺序，金额小数点和单位对齐。差额、币种及匹配依据靠近确认操作 | 每个字段的一对值上下相邻，保留来源列名。差异筛选后仍能展开一致项 |
| CRM 客户档案、病历资料、设备履历，连续查看多个对象 | 记录索引加详情。详情首部固定对象身份，再按时间读历史或按主题读属性。切换记录后详情标题和动作对象同时更新 | 详情成为单独页面。返回后恢复筛选、选中项和列表位置，避免重新搜索 |
| ERP 订单、WMS 拣货与盘点，反复核对多行 | 订单横向比较靠表头与列对齐。仓内执行可按库位和行走顺序分组，将品项、单位、应拣量、实拣量放在同一行 | 现场视图优先当前库位与下一件。可在详情核对完整单据，调整数量后仍可追溯具体行 |
| MES 排程、门店排班、资源预约，找可用时段 | 用资源行和时间轴呈现占用关系。连续空档能被看见。选中条目后在旁边改资源、开始和结束时间，给拖拽提供等价控件 | 把同一资源的班次排成时间列表，显示起止、时长及冲突对象。移动时同时校验目标资源与日期 |
| CMS 内容审校、合同修订，边读边改 | 正文承担最大阅读面积，批注或版本差异放侧栏。评论连到段落，操作标明处理的是哪个版本 | 保留正文锚点，按需展开当前段落的批注，关闭后回到刚读的位置 |
| OA 审批、客服工单、政务受理，决定下一件办什么 | 按待处理队列组织，队首能看出优先原因。详情先给决定所需的事实，再给同意、转派或补件等有效动作 | 每次处理一件。提交后明确剩余队列和当前筛选，退回补件时保留原因 |
| 公共服务、自助申请、员工门户，从入口开始一件事 | 高频事项与进行中事项分别可找。进入事项后保留对象、材料、办理步骤和结果查询入口 | 有带参入口时可直达事项。仅在用户需要选择服务时展示服务目录 |

若任务围绕商机或内容在多个阶段间流转，看板按阶段分列，卡片上保留移动依据和下一步。需要比较每条商机的金额、负责人和跟进时间时，可改用按列对齐的表格。同一批数据选哪种版式，取决于当前操作。

排程冲突可用相邻工单检验。08:00–10:00 已被占用，09:45 开始的工单应提示冲突资源、重叠时段和原工单。若业务允许交界接续，10:00 开始可以衔接；若有清场或换型时间，应把缓冲计入占用。提交失败时保留当前编辑值和原计划，方便调整。实际方案以项目业务规则为准。

## 把颜色落实到组件

以下色值是可替换的起点。先选表面与文字，再分别选动作和状态。表内分别给出正文与页面底色、按钮文字与实心按钮的对比度，按不透明 sRGB 计算，数值四舍五入。更换背景或使用遮罩时，以最终像素重新计算。

| 阅读场景 | 页面底 / 正文 | 正文对比 | 按钮底 / 按钮字 | 按钮对比 |
| --- | --- | ---: | --- | ---: |
| 高频核对，冷灰底、墨蓝动作 | `#F6F8FB / #172E46` | 13.02∶1 | `#234D79 / #FFFFFF` | 8.72∶1 |
| 产线计划，温灰底、靛蓝选中 | `#F6F5F0 / #262B3D` | 12.87∶1 | `#443C80 / #FFFFFF` | 9.53∶1 |
| 现场服务，浅灰绿底、松石色动作 | `#F5F8F4 / #142F2B` | 13.33∶1 | `#00675D / #FFFFFF` | 6.78∶1 |
| 文化档案与出版，纸色底、棕红动作 | `#FAF5EE / #372A26` | 12.72∶1 | `#854124 / #FFFFFF` | 7.56∶1 |
| 低照度值守，深蓝灰底、浅蓝动作 | `#121B26 / #ECF3F8` | 15.48∶1 | `#9DCBFF / #152A42` | 8.61∶1 |

例如，计划板可以用靛蓝描边和“已选”共享选中语义，用深褐字 `#664100` 配浅琥珀底 `#FFF1CF` 表示“排程冲突”（8.07∶1）。当选中工单恰好有冲突，保留选中轮廓，同时在时段旁显示冲突文字与图标。品牌本身使用绿色时，“已完成”仍需要动词或对勾。

分类图按固定对象分配类别色，时间或数值强度可用连续明度，有业务中点的正负偏差可用发散色并标明中点。优先给必须比较的类别明确图例、标签或绘制形状。坐标轴文字承担阅读功能，单独检查对比；背景网格线可更弱。项目手册已有财务涨跌色、医疗风险色或设备告警等级时沿用其语义。

实测亮橙 `#F7B452` 上白字只有 1.81∶1，改用 `#29313A` 深字达到 7.28∶1。普通文字常用的 WCAG AA 门槛为 4.5∶1，达标后还要在实际字重和字号下检查。产品色、功能色与可视化色可按角色组织。[Ant Design 色彩](https://ant.design/docs/spec/colors-cn/) · [W3C 文字对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
