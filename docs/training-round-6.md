# 第六轮 · 搜索、筛选、对比与批量处理

第五版已经要求搜索和筛选同步更新结果。这一轮进一步区分三种任务。辨认材料时，样本图需要有可比较的尺度和可读的名称。核对规格时，同一属性要放在同一行或同一组。办理设备时，用户需要知道确认按钮将作用于哪些编号。[搜索与选择指南](../frontend-design-studio/references/discovery-selection.md)

## 判断依据

用六条有名称、材质、色调和领取资格的虚构记录复算。暖色、名称含“纹”的木材命中两件，石材命中一件。若接受任一种材质，追加石材后是三件。“石材 1 件”和“应用后 3 件”计算的是不同范围。若要求场地同时具备两种设施，集合关系也随需求改变。

| 编号 | 名称 | 材质 | 色调 | 当前可领取 |
| --- | --- | --- | --- | --- |
| S1 | 松纹 | 木 | 暖 | 是 |
| S2 | 橡纹 | 木 | 冷 | 是 |
| S3 | 砂纹 | 石 | 暖 | 否 |
| S4 | 青岩 | 石 | 冷 | 是 |
| S5 | 胡桃纹 | 木 | 暖 | 是 |
| S6 | 素纹 | 布 | 暖 | 是 |

初选的三件中，有一件当前不可领取。它仍可参与规格对比。若在全部三件中准备领取两件，其中一件在确认前被他人领取，这次操作与撤销都只应作用于实际变更的那一件。这组六条记录通过了九项数量与编号断言。

选择立即更新或集中应用时，要考虑面板是否遮住结果、组合条件是否常见。手机将未应用的选择保存在面板内，取消时恢复原条件。列表、计数和标签均应能解释当前展示的集合。[Carbon 筛选指南](https://carbondesignsystem.com/patterns/filtering/) · [Carbon 数据表](https://carbondesignsystem.com/components/data-table/usage/)

## 如何评审

| 样页 | 建议复查的路径 |
| --- | --- |
| 物样 · 材料样本馆 | 组合材质和用途，打开样本详情再返回。保留一个候选，换筛选条件，再添加第二个材料进行对比。制造一次零结果，只移除一个限制。 |
| 北线 · 设备巡检台账 | 勾选本页设备，翻到另一页或更改筛选，再核对清单。确认要处理的编号与数量，执行后撤销并检查状态。 |

两页的详情意见带有材料或设备编号。同一页中切换记录后，可以利用编号定位到原对象。第六版评审文件继续使用 `forma-review/v1`，已有样页的步骤、评分和意见仍可导入。样页使用虚构数据，材料纹理用于辨认演示，设备办理结果保存在当前浏览器。

## 样页实测

- **材料样本馆。** 12 款程序生成的纹理涵盖石材、木饰面、织物、釉陶。移除导致零结果的色调后，仍保留木饰面条件，列表恢复为 3 项。手机取消筛选和按 Esc 都保留原条件。从第 11 款样本 TX-03 进入详情后返回，焦点回到原链接，滚动位置恢复到 798px。对比表支持两至三款材料，厚度统一用 mm，参考单价统一用元／㎡。
- **设备台账。** 15 台设备每页显示 5 台。一次跨页勾选 6 台，核对页显示 4 台可加入、2 台跳过及原因。另一标签页先办理一台时，需要重新核对剩余范围。刷新后可以撤销实际加入的记录。改区域时会清除先前 15 台的勾选，并说明清除数量。
- **窄屏操作。** 台账初版行内勾选框的实际点击区域为 17×17 CSS px。调整为 44×44 的标签热区后，在 390px 视口点击方框外的留白只会勾选，点击相邻设备名只会打开详情。材料卡的对比按钮也经边缘点击验证。两个公开样页各在 320 至 1440px 的七种宽度接受布局检查。
- **标注。** 在 ST-01 详情留下意见，再打开另一种材料，原标记随即隐藏。点「定位」后重新打开 ST-01，标记回到原标题。对设备 NL-101、已移除的编号、第五版 JSON 导入和 Markdown 导出也做了浏览器检查。

## 换一个任务验证

独立试用者只读取新版 skill 及其引用，为音乐老师制作了一个包含 8 个虚构排练空间的 H5 目录。先勾选河东，得到 2 个空间，再加河西得到 5 个。要求钢琴时剩 4 个，同时要求无障碍入口后剩 3 个。对比页能核对柳堤琴室的 12 人、每小时 ¥60 与旧埠室内乐坊的 16 人、每小时 ¥85。

从旧埠详情返回，四项条件和两个候选仍在，焦点回到旧埠链接，滚动恢复至原先的 287px。独立试用检查了 320、390、1440px 的 Chromium 视口。真实材质、联网台账、移动操作系统手势与读屏朗读均超出本轮实测范围。
