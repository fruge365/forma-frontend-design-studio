# 第九轮 · 一份内容如何从屏幕走到纸面

音乐节观众要带走自己挑选的场次，设备值班员要在换班后查回一份交接记录。前者需要按日期编排可变的节目集合，后者需要保留某次交接的版本。两种做法已写入[屏幕、纸面与可重印单据指南](../frontend-design-studio/references/screen-and-print.md)。

## 导出与浏览器核验

使用 Chrome 打印引擎生成 A4 纵向 PDF，缩放 100%，关闭背景图形和浏览器附加页眉页脚。对空收藏、两天的单日节目、跨日收藏、早班草稿、生成单、历史目录及重印逐项核对。空收藏导出零场演出，两个单日各有四场。交接单在 P-14 与 P-15 之间换页，P-01 至 P-22 各出现一次，第二页读得到末条及“清单结束”。另用 Letter 纸型和 460 字交班备注检查分页。随仓库提供的两份 A4 样张经中文文本提取和逐页图像复核。

屏幕侧在 320–1920px 的尺寸范围检查两页。390px 下第一场原有一行只剩“琴”字，调整后窄屏将演奏团体和乐器编制分行，乐器名在同一阅读段内换行。空节目单最初还带有“返回日程”的屏幕指引，现将返回操作留在网页，纸面明确显示空清单。

纸面标注保存当时的日期、跨日选择或单据版本。在“我的节目”标注周日的演出，再切到“周日全部”，两份纸面都有同一曲名，原图钉只在原集合出现。打开另一份交接单也会按单号匹配。实测图钉在打印媒介中隐藏；导入第八版地点标注及评分仍保留原值。[浏览器回归脚本](../scripts/paper-browser.cjs)

## 换成陶艺教室的烧制档案

独立试用者只拿到技能和双批次陶艺记录的需求。试作中同一只折沿茶碗有两次出窑记录。核对初烧和复烧的纸样，均为一页；前者可检索到 PS-1022-01、1220 ℃ 和一号电窑，后者为 PS-1103-01、1205 ℃ 和二号电窑。技能因此补充了一个验收办法：用同名对象的两次记录做样本，直接从两个输出文件核对有差异的字段。

本轮实际核验到浏览器生成的 PDF。系统打印窗口的取消操作、实体打印机的留白与线条效果仍需在相应设备上检查。
