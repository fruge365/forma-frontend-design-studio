# 地图、平面图与地点列表

## 先说出看图才能得到的答案

“哪个展厅与入口同层”“过桥后先到哪一站”值得给图留出主位。按名称找货位、按时间查看待办，则让搜索或清单先出现。用户既要找对象又要辨方位时，宽屏可并排展示，窄屏可切换。两个入口都应能找到同一对象、读到决定下一步所需的详情。

| 用户要判断什么 | 图面需要表达什么 |
| --- | --- |
| 某地在城市的哪个方向，步行多远 | 地理图保留有依据的位置、方位。给距离写明起点和口径，如“从东门沿步道 600 米”。展示比例尺时使它随缩放更新。 |
| 先到哪站、在哪里换线 | 示意图保留次序、连接和方向，图旁标示“路线示意”。图形按阅读需要排布，行程数据另取自路线资料。 |
| 某货位或展厅在入口的哪一侧 | 平面图保留楼层、墙、通道、出入口与地址。用入口或轴线建立朝向，跨层时标明层号。相邻的两个区域若被墙隔开，绘出实际连接它们的门或通道。 |

故宫的《故宫零废弃》导览手册给地点分配 A–G 编号，目录按地点列出内容，两条游览路线分别列出经过的编号。可借鉴的是地点与行程各自有稳定含义。在交互页面中，筛选和排序后保留地点编号，把“本线路第几站”另外表达。[故宫博物院官方导览手册（PDF）](https://young.dpm.org.cn/uploads/1/file/public/202505/20250516181259_97digy9q27.pdf)

## 在图、列表和详情之间保留同一个对象

从同一组记录生成标记、列表和详情，用稳定 ID 联动。类别筛选可以减淡底图地标，但可选择的点与列表结果应对应。列表可按距离、路线或优先级排序，界面写清依据。若列表含图框外的对象，明确“全部结果”与“当前图内”的范围，选中后给出定位入口。

判断编号在哪个范围内唯一。两个放映厅都可能有 C 排 04 号，同一座位在两场电影里的可售状态也会不同。选择和回执应带上场次，核对区同时显示场次、厅和座位；切换场次时按新场次读取状态。恢复某个空间对象时，只解除遮住它的筛选，保留仍匹配的查询条件。

Apple 地图的“附近”搜索允许按类别查找，也可移动地图来更改搜索区域。迁移时明确产品中移动图面的含义。浏览固定场地时保留查询范围；按视野检索时，在图和列表旁共用范围提示，说明结果已更新，或提供“搜索此区域”。[Apple 地图官方使用手册](https://support.apple.com/zh-cn/guide/iphone/iphbaf51b2c0/ios)

切换显示方式时带上查询、楼层、筛选和当前对象。若新的筛选排除了它，可收起详情并提示原因，也可标为“当前对象不在结果中”。空态写出阻止命中的条件，提供就近的修改入口。关闭详情后，焦点回到原对象的按钮；原按钮已隐藏时，回到仍可操作的结果入口。

选中货位只改变浏览位置。发起盘点、加入行程等写入动作在显示对象名称与编号的控件上单独触发。若操作期间可继续浏览，用发起时的对象 ID 绑定操作和回执。清单依然按记录的状态显示，例如给 A03 加入盘点任务后，A03 的库存数量保留到实盘更新。

## 窄屏保住标记的分辨率

用底图交代河岸、墙体或通道，用符号与短标识呈现对象，用外圈或文字指明当前选择。状态可用纹样、形状或直接标字，图例复用图上的记号。把焦点轮廓留给键盘操作。密集区域可合并为带数量的组，点开成员，或在原坐标旁用引线引出标签。实测按点时的有效区域，尤其是叠在相邻点上的透明热区。

WCAG 2.2 的最低目标尺寸是 24 × 24 CSS 像素，并规定间距、同页等效控件等例外。W3C 以必须保留真实坐标的密集地图针举例。空间受限时，可给每个点提供同页可点的列表行，保留完整名称和操作。若自绘地图支持拖动平移，又需要浏览图内任意位置，给它加可点按的方向控件，并另测键盘操作。[W3C 目标尺寸说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum) · [W3C 拖动操作说明](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements)

## 用同一个地点走两遍

挑两个相邻、名称相似的对象。先点最密处的标记，再只用键盘从列表找到同一对象，读出编号、方位和下一步。窄屏切换视图，再筛到零结果并恢复，核对图、清单和详情指向的编号。若有作业操作，先为 A 发起任务，查看 B，再核对记录归属及两者的业务状态。涉及真实导航或现场作业时，到场核对现场方位和通道，浏览器内的预览只验证界面行为。
